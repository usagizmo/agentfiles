# 渡しの記録（merge の枠）

**merge の枠を誰に渡したかを外部化したもの**。merge は唯一の直列化点で常に 1 件しか進めないが、
**渡した相手は追随の push で `着地待ち` から外れる**ので、現在の状態からは「いま誰が着地してよいか」を
復元できない。**この記録が権限の実体**で、状態は権限を表さない。

**書くのも消すのも上位のキュー管理**。**着地する側は読むだけ**で、自分では書かない・消さない。
**書く契機・消す契機・回収してよいかの判定は、キュー管理側の skill が SSOT**。

````markdown
<!-- integration -->

```yaml
issues: [<Issue 番号>] # 対象集合の全番号
pr: <PR 番号> # 監査用
```

<!-- /integration -->
````

**同じ marker のコメントを複数作らない**。**代表の Issue に 1 つ**（帰属は `same-branch.md`）。

**照合は `issues` で行う**。`pr` は監査用で、判定に使わない —— PR を作り直すと番号が変わるので、
そこで照合すると**自分に渡された枠を自分で失効させる**。

**2 件以上あったら異常として報告する**。どちらが権限か決められないので、勝手に 1 つ選ばない。

## 着地する側

**着地の直前に、記録が自分の対象集合を指していることを確かめる**。指していなければ着地しない。

**枠を待つ variant にだけ効く**。人から 1 件を直接頼まれて単独で走る variant は枠を待たないので、
記録の有無を着地の条件にしない（**しないと、記録が存在しえないぶん永久に着地できない**）。
