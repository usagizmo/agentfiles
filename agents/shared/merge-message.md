# マージコミットのメッセージ

直前コミットの言語・スタイルに合わせ、gitmoji を 1 つ選ぶ（`gitmoji.md`）。タイトルを `Merge branch '...'` 等の既定文にしない。

## PR の merge

```
{gitmoji} {変更内容を凝縮した説明} (#N)

- {コミット群の要約1}
- {コミット群の要約2}
```

件名の末尾に `(#N)` を必ず付ける。body はコミット群の箇条書き。不要なら空にする。PR のコミットが 1 本なら body は空にする（件名と同じ 1 行を箇条書きで繰り返さない）。

## ローカルの merge commit

```
{gitmoji} {変更の本質}

- {サマリー1}
- {サマリー2}
```
