# 記法

agent-facing 文書の記法。語・文のレベルは `~/.agents/AGENTS.md` の「文章の書き方」。

## 強調

規則そのものは太字に**しない**。

太字にするのは、読み違えると逆の結論に着く語だけ:

| 対象             | 例                           |
| ---------------- | ---------------------------- |
| 否定と限定       | ない・禁止・不可・のみ・だけ |
| 例外             | 例外は〜のときだけ           |
| 対の条件の差分   | 前者は〜、後者は〜           |
| そこで定義する語 | 用語をその行で定義するとき   |

段落・表のセル・箇条書きの項目それぞれで 1 点まで。

## 形の選び方

- 規則が 3 つ以上並んだ段落は、散文のままに**しない**
- 表にするのは全行が同じ列を持つとき。列が揃わないなら箇条書き。短くする手段では**ない**
- 表のセルは 1 行に収める。理由・実例・例外を詰め**ない**。詰まるなら表の外へ箇条書きで出す

幅で折り返さない。文の切れ目での改行は残してよい。判定は `<skills root>/docs/scripts/check-hard-wrap.ts`。

## Markdown 記法

強調は描画で `**` が残る形に**しない**（約物で閉じた直後に語を続ける `**規則。**続く` が典型）。

判定は `<skills root>/docs/scripts/check-emphasis.ts`。
