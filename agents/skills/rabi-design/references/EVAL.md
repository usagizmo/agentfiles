# 評価シナリオ

## 回し方

お題・渡すもの・媒体・harness・model を固定し、変える入力を `DESIGN.md` と `../assets/` だけにする。

同じお題を、変える前と後で回す。**前は直す前に回す** —— 書いた瞬間に配られるので、直したあとに前の版は作れない。

生成物は repo の外へ置く。tracked にし**ない**。

## 当たりの取り方

生成物を開いて、名で当たりを取るのは人。agent が渡すのは生成物の在処と、回した 2 版の差。

規則をここへ書き直さ**ない**。

同じ名が 2 周続けて出たら、落とす先を選び直す（`../SKILL.md`「指摘を落とす先」）。

## シナリオ

媒体は `DESIGN.md`「Components」の媒体表の第 1 列、見る軸は「失敗パターン」の名。

**この表も gate が読む入力**。見出しの行と列の順を変え**ない**。

| お題       | 媒体                             | 渡すもの                                             | 見る軸                                                                                                                    |
| ---------- | -------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 見積       | 文書（見積・譜面・PDF）          | 品目 8 行・グループ 2・合計 1・宛名と発行日          | 赤を足して強調する / 段の間の値を作る                                                                                     |
| 業務の画面 | UI。意味ロールが 2 つ以上並ぶ面  | 一覧 12 行・絞り込み・欄 6・情報と成功と注意の添え物 | 地を塗って状態を示す / 状態を class で受ける / 意味を色だけに載せる / 押せない面を hover で動かす / 押せる行を div で組む |
| 宣伝の頁   | UI。それ以外                     | 表紙の見出し・価格 3 プラン・導入事例 4・問い合わせ  | 影で階層を作る / 丈と別に文字や余白を決める / 赤を足して強調する                                                          |
| 読み物     | UI。それ以外                     | 見出し 3 階層・コードの塊 2・添え物 2・表 1          | 罫を足して面を分ける / 部品の値を面から上書きする                                                                         |
| 図         | UI。それ以外                     | 工程 6 ノードの流れ図・強調 1                        | 赤を足して強調する / 意味を色だけに載せる                                                                                 |
| スライド   | CSS を持たない（docx・スライド） | 表紙 1 枚・本編 5 枚・数値の頁 1 枚                  | 段の間の値を作る / 意味を色だけに載せる                                                                                   |
