# `Same branch as #N`

Issue 本文に書く宣言。**「この課題は #N と 1 本のブランチで直す」**という意味を持つ。
気づいた側が、**関係する全 Issue の本文へ相互に書く。**

この宣言で結ばれた Issue の集合を **group** と呼ぶ。**group は推移的に閉じる** — A↔B と B↔C が
書かれていれば A・C も同じ group。相互記載が漏れていても、辿れる限りを 1 つとして扱う
（閉じないと 1 つの group が 2 本のブランチに割れる）。

## 書く条件

**片方だけ直すと、もう片方が同じ場所を二度触る**とき。テーマが近いだけでは書かない。

## 隣接する記法との違い

| 記法 | 意味 | 作業単位 |
| --- | --- | --- |
| `Same branch as #N` | **同居** — 1 本のブランチで一緒に直す | 同じ |
| `Depends on #N` | **順序** — #N を先に片付ける | 別 |
| `Refs #N` | 関連するだけ | 別 |

## 本文に書く理由

Issue 本文はセッションより先に存在する。だから着手する側は、**最初の 1 手で group 全体を
1 本として取れる。**

宣言が無いと、同じ場所を触るものが別々に着手され、並行した 2 本が rebase 衝突を作る。
