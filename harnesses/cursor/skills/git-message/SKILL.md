# git メッセージの書式

| 書くもの                                    | 書式                           |
| ------------------------------------------- | ------------------------------ |
| コミットメッセージ                          | `references/commit-message.md` |
| PR のタイトル                               | `references/pr-title.md`       |
| PR の merge commit・ローカルの merge commit | `references/merge-message.md`  |

gitmoji は `references/gitmoji.md`。repo の AGENTS.md 等にスコープや gitmoji の規約があれば、それを足して従う。
